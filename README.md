# 纯白铃铛

> 基于 Qt 的 QQ 机器人管理平台 —— 多账号托管、多语言插件、注册式规则，一个窗口全管完。

![License](https://img.shields.io/badge/license-LGPL--3.0-blue.svg)

![Qt](https://img.shields.io/badge/Qt-5.15-41cd52.svg)

![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux-lightgrey.svg)

纯白铃铛不追求"大而全的协议库"，而是把**插件体系、规则管理、运维工具**做在一套原生桌面程序里：  
装好就能用，插件点一下就装，规则改完立即生效。下面只列与其它框架不同的地方。

## 亮点速览

**接入与上传**

- 多账号托管，同时支持 **WebSocket** 与 **Webhook** 两种接入方式。
- 自动内网探测：文件上传优先走腾讯云内网链路（仅限腾讯云服务器），省流量、速度快。

**插件体系**

四类插件共存，并可分别对**单个机器人**授权开放：

| 类型         | 语言 / 形态      | 运行方式              |
| ---------- | ------------ | ----------------- |
| Python     | `.py`        | 进程内 pybind11 绑定   |
| 原生         | x64 DLL / SO | 直接加载调用            |
| 易语言        | 32 位 DLL     | 共享内存桥接（异步、多路）     |
| JavaScript | `.js`        | 独立 Node 子进程（管道通信） |

- **注册式规则**：插件只负责注册指令，触发方式交给用户 —— 自定义指令词、单条启用/禁用、指定触发人、改写发送内容、按标签分组，全部在界面里改，不用碰代码。
- 内置图床、全局缓存、自动撤回（O(1) 查找）、文本注入检查（防止用户复读指令撑爆上下文）。

**内置能力**

- 全局商店：插件可注册商品并自定义价格，统一货币与积分体系。
- 常用插件开箱可用：关键词回复（AC 自动机）、定时 / 订阅推送、AI 对话、素材管理、指令编辑、文本替换、违禁词、黑名单、批量推送、按钮生成，以及入群、机器人入群等各类事件处理。
- 内置 AI 长期记忆：会话记忆落在本地，向量检索用 LMDB + hnswlib，不依赖任何外部向量库。
- 内置**插件市场**：点一下安装到框架，不用去浏览器下载、复制文件，也不用命令行。
- 内置群管：禁言、加群验证、自动同意加群、按指令禁言某人、批量撤回某人的消息。
- 音频转码 长度超5分钟自动分割发送

**运维与性能**

- 日志按类型分开：事件、群、私聊、频道、频道私聊、发送错误，共 6 类。
- 每个事件投递给插件时都带**群名、用户名**；私聊与入群申请也带昵称。框架还给每个用户分配了整数短 ID，写游戏类插件时短 ID 更好存、更好查。
- 内置指令耗时统计，插件执行耗时也能接入。
- 为吞吐而设计：事件接收到投递进线程池约 **0.1ms**（视机器配置、数据库写日志耗时），理论上单核可处理 **约 400 条/秒** —— 实际取决于插件本身的执行耗时。

> 说明：内置"插件生成"功能已弃用；内置聊天室的界面还在打磨，功能可用但 UI 不完善。

## 快速开始

### Windows

1. 从 [Releases](https://github.com/qiancao1/chun_bai_ling/releases) 下载 7z 压缩包。
2. 解压到任意目录。
3. 运行 `纯白铃32.exe`：
   - 输入 `0` 回车 —— 补全运行数据；
   - 输入 `1` 回车 —— 安装微软常用运行库；
4. 关闭 `纯白铃32.exe`，运行 `纯白铃铛.exe` 即可。

### Linux

发布包内附带一个 `.sh` 脚本，复制到服务器上直接执行即可完成部署。
注意群里面提供 纯白铃-linux-远程桌面.exe 下载 他的专用是 在win显示 linux 窗口 如果你使用webui 可以不下载这个 webui可能不好使 但是基础都有
群就不放这里了 框架里面的关于有

## 账号配置

1. 点击「添加账号」，填入 **Appid** 与 **Secret**，保存后登录。
2. 首次使用、且只用本框架时，可以直接**扫码登录**，无需手动填密钥。
3. 接入方式可选 WebSocket 或 Webhook。

配置完成后，在群里 **@机器人 发送「纯白铃」** 即可查看内置指令。  
注意：需要先把自己设为该机器人的**管理员**才能看到完整指令列表 —— 管理员权限意味着能重启框架、改配置，只给自己就好。

界面上还有个「全局管理」入口，可以重启框架、获取 WebUI 链接。

## 插件体系

插件是纯白铃铛的核心。三类关键设计：

1. **注册式而非硬编码**：插件声明"我能处理哪些指令"，具体触发词、触发人、发送内容由用户在界面里配置，改完立即生效。
2. **按机器人授权**：同一个插件可以只对某几个账号开放，多开互不干扰。
3. **多语言一视同仁**：Python、原生 DLL、易语言、JS 都能注册指令、注册商品、调用框架 API。

框架为插件提供的 API 涵盖收发消息、图片 / 语音 / 视频 / 文件上传（带跨次缓存 **内网上传仅限腾讯云服务器** ）、群管理、按钮等，Python 侧见根目录 `qiancao_sdk.py`。

## 从源码构建

依赖：**CMake ≥ 3.16**、**Qt 5.15**（Widgets / WebSockets / Network）、**OpenSSL**、C++17 编译器。  
Windows 端默认使用 **free-threaded Python 3.14t**（路径在 `CMakeLists.txt` 的 `PYTHON_FT_ROOT`，也可用 `-DPYTHON_FT_ROOT=...` 覆盖），Linux 端默认 `/usr/local/.../python3.14t`。

```bash
git clone https://github.com/qiancao1/chun_bai_ling.git
cd chun_bai_ling

# key.txt 是可选的：里面是加密用的宏，不存在也能正常编译（此时用空密钥）
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

产物：`qiancao` / `qiancao.exe`。第三方库以源码形式放在 `libs/` 下（LMDB、hnswlib），随主工程一起编译，无需额外安装。

## 项目结构

```
core/        核心：QQ 协议客户端、消息处理、存储、上传、缓存、音频转码
network/     网络层与连接管理
ui/          全部界面（账号、规则、日志、聊天室、插件市场、AI 等）
plugin/      插件加载、安装、市场、Node 宿主管理
python/      pybind11 绑定与 32 位共享内存桥
node_host/   JS 插件的子进程宿主
ai/          内置 AI 能力与审核、表情包等辅助模块
db/          数据目录与 AI 向量记忆（LMDB + hnswlib）
libs/        第三方源码（LMDB、hnswlib）
```
