# ============================================================================
#  纯白铃铛 —— 自编译 FFmpeg 的「音频解码器」白名单（Windows / Linux 共用）
#  由 ff-config-flags.sh 的 qc_ff_decoder_list() 读取后拼成 --enable-decoder=
#
#  ⚠ 只放**常用**的。别恢复成「全部音频解码器（178 个）」：
#     全量名单会让 libavcodec 的 .def 生成命令涨到 10 KB+，
#     而原生 make → MSYS sh 这一跳在 8192 字节处硬截断 → 编译必挂在 .def 那一步。
#     详见 ff-config-flags.sh 顶部说明 + build-win.sh 里的长度自检。
#
#  加名字之前先对一遍源码（拼错的名字 configure 会**静默忽略**）：
#     grep -o 'ff_[a-z0-9_]*_decoder' libavcodec/allcodecs.c \
#       | sed 's/^ff_//;s/_decoder$//' | sort -u | grep -qx <要加的名字>
# ============================================================================
